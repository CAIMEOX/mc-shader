# Y2K

An Iris post-processing shader pack for Minecraft Java Edition 26.2. It gives
the rendered world a restrained turn-of-the-millennium digital-camera look:
silver/cyan shadows, magenta highlights, RGB lens separation, compact bloom,
scanlines, a pixel grid, sensor noise, vignette, and occasional horizontal
glitch bands.

The filter runs in the final pass, so Minecraft's HUD remains crisp. Open
Shader Pack Settings to choose the Soft, Y2K, or Cyber profile, or tune each
layer independently. Setting **Y2K Intensity** to zero restores the unfiltered
scene without changing packs.
